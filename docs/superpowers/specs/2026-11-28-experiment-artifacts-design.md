# 实验产物、批次指标与独立评估

本次修改在独立 worktree 中完成。原工作区仍在采集示教数据，不能更新其 Python 源码、迁移文件或重启进程；新版本在下次启动时使用。

实验根目录包含四个职责明确的目录：`datasets` 保存示教轨迹及采集清单，`weights` 保存策略 checkpoint 和固定权重快照，`logs` 保存配置、运行状态、训练历史、诊断、录屏和可再生缓存，`eval` 保存训练后的独立评估轨迹及逐回合/汇总 JSON。TensorBoard 继续放在 `tf-logs/<experiment>/<task>/<run>`。旧目录不自动搬迁。

追加约束：任一父目录已有同名实验（包括空目录），新算法启动直接抛出 FileExistsError；检查发生在写配置、设置缓存和启动服务之前，并用 mkdir(exist_ok=False) 处理并发冲突。不提供 CLI 续训入口。serve 仅查看已有实验，保留原配置。分阶段算法运行各用新实验名，通过外部 manifest/checkpoint 引用旧产物。

轨迹以 `np.savez_compressed` 原子写入，使用数值数组与 UTF-8 JSON 元信息，不使用 pickle，不再同时保存完整轨迹 JSON。观测与标签沿用现有训练数组协议。读取层兼容旧 JSON 和旧 NPZ 训练缓存；回放目录枚举 NPZ，HTTP 按需转换为前端现有 JSON 协议，转换结果不持久化为第二份大型轨迹。采集清单仍是训练样本的权威来源，失败轨迹不能混入训练。

训练、验证分别有 batch size，入口默认均为 4，序列长度 64。一个 mini-batch 是最多 4 条平行轨迹的连续 64 步，实际样本数为排除 padding 后的动作标签数，最多 256；保留 GRU 因果状态和 TBPTT。每个训练更新或无梯度验证批次结束后写入并 flush Loss、Action MSE、Action MAE、Samples。保留每个 epoch 的六条指标；批次独立计数并随 checkpoint 恢复，防止续训复用步数。CPU/显存不足时可以降低两个 batch size，不自动启动性能压测。

训练和验证完成后固定 checkpoint，以不参与收集、训练或权重选择的场景评估每任务 30 个 episode。默认纯网络推理，显式约束模式保留真实控制模式标记；正式协议以声明的主模式评估 30 回合。各回合保存 NPZ，`episodes.json` 包含种子、模型 SHA、成功标志、终止原因和真实汇总，`summary.json` 包含胜率、数量及完成状态。初始化/运行错误也计入失败，分母始终是要求的 episode 数；中断时保持 incomplete。最终测试结果不能用于挑选权重。
