# 引斥场、顶部菜单、主题与实验输出

保留现有静态 ES module 前端与实时、回放数据协议。引斥场使用真实 `frame.potential`：正值青绿、负值紫红、硬约束珊瑚红，绝对值越大色块越深，固定色标不随帧归一化。

新增独立的“场方向”开关，保留场值色块开关。箭头使用物理米制间距下的相邻栅格有限差分，沿偏好值增大的方向（正梯度）；内部中心差分，边缘及掩膜旁单侧差分，无有效邻点或平坦区不画箭头。不将掩膜外的零当作真实场值。方向与场值均取当前帧，暂停、回退、切换任务时无未来信息。

新增跟随无人机的“引斥场”近景视角。箭头按屏幕像素间距抽样，避免全域视图拥挤；保持笛卡尔 +Y 向上。图例说明颜色、方向、平坦区域，缺少场数据时明确提示。图层选择随场景切换保留。

所有操作集中在顶部菜单栏：任务切换，以及数据、视图、播放、录制菜单。视图中集中所有可视化开关、相机、轨迹样式、缩放和主题；播放菜单容纳时间轴与回放操作。一次只打开一个菜单，支持键盘与手机尺寸。

默认白色主题，提供原深海蓝海图主题并记住选择。两套主题分别配置面板、文字、栅格、ROI、云、岛、无人机、船舶、雷达、轨迹及录制配色；保持语义与辨识度。沿用真实照片与模型素材，图例位于地图外。

顶部录制菜单提供录制开关，使用真实回放或实时帧。历史演示按录制时长推进完整回放；手动关闭或定时结束后自动上传并转为 H.264 MP4，视频和来源元数据保存在当前输出目录的 recordings 下。显示设置、状态、目录和下载链接。处理准备、录制、保存、错误及重试，保留自动化录制 API。

`main.py --experiment-name NAME` 将输出与缓存放入 outputs/NAME，TensorBoard 放入 tf-logs/NAME。校验 NAME 为安全的单层目录名，`--run-name` 保持任务内部的日志运行名。`run.sh` 默认 NAME=formal，维持既有正式实验路径；直接调用 main.py 不传新参数时兼容旧路径。当前算法及 TensorBoard 不重启、不停止，新启动时应用目录参数。完成检查后提交并推送当前 GitHub 分支，排除用户已有文档修改。

验证：有限差分方向、物理间距、掩膜、常量场、异常输入、窄边界抽样、真实 Canvas 绘制、图层偏好；主题、录制生命周期、服务端转码、实验路径隔离回归；Playwright 检查真实桌面与手机回放、菜单和键盘、双主题、独立开关、回放进退、缺场数据、自动保存 MP4 和浏览器错误。使用独立测试服务，不触碰运行中的算法。
