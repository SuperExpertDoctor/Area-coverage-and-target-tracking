# 验证状态与适用范围

这里区分源码功能、专家行为和神经网络闭环效果。所有数字来自真实仿真，不把混合专家控制的DAgger轨迹当作纯网络部署。

## 专家与跟踪网络

覆盖专家seed7100连续10800秒达到100%海面格覆盖，首次完整覆盖3740.5秒；最终平均扫描年龄1191.4秒、最大7456.7秒。它支持持续重扫，但没有固定的最大重访时间保证。

跟踪专家seed7101连续1800秒全程真实可见。跟踪网络的7个诊断测试（7101、7105、7111、7301—7304）均持续1800秒全程可见，无碰撞或越界；全部回合距离范围1541.1—2295.5m。其验证MSE从0.001296降至0.0001018。

扩大专家验证的案例在执行前写入manifest：30个独立覆盖随机种子、3个固定ROI各8个均匀边界起点、10个跟踪种子。除真实初始碰撞/越界/非法bank外不筛掉困难案例；已运行后失败仍必须计入。结果带源码和物理配置哈希，修改相关源码后旧结果不充当新版本通过证据。完整实际统计位于本地`outputs/diagnostics/expert-randomized/suite-summary.json`。

首轮完整64例为63通过、1失败：54个覆盖案例全部3小时安全且100%首扫；跟踪5003在1190.2秒丢失目标，最远7054.5m。该反例不是初始状态非法，未从统计中剔除。实际A*绕岛船路比原螺线更接近云，原额外1300m软引导缓冲导致绕行过远。修复只调整跟踪专家额外软缓冲，硬云边界、转弯物理和30秒预测保持原值；前后对照及新版本整批复验结果分别留档，不能把旧批次63例通过冒称新版本64例通过。

发现的覆盖seed2000反例已保留并修复：原安全筛选只检查有限偏移方向，漏掉当前航向这一可行候选；现在仅在原候选全失败时检查保持当前航向，仍使用同一真实动力学预测和碰撞条件。修复后5400秒达到100%覆盖，未降低安全约束。

## 覆盖网络仍未达标

覆盖网络已有独立CNN/MLP/GRU、序列BC、训练场景DAgger、分组验证及可复现checkpoint。不同尝试均显示离线拟合不能替代长期闭环：

| 实验 | 离线结果 | 闭环发现 |
|---|---|---|
| 机体系BC | 验证MSE约0.00480 | 纯网络出现持续局部绕圈，覆盖不完整 |
| DAgger第一轮 | 验证MSE约0.00453 | 同场景3小时仅约22.8%覆盖 |
| 世界坐标、稠密坐标地图、12条专家、60轮 | 验证MSE1.013→0.00694 | 3个验证场景best覆盖率29.33%、20.76%、7.89%，仍未完成 |

世界坐标实验的best与last共6次验证均未完整覆盖，5次碰撞或越界。数据、权重、哈希、完整回放和详细分析位于本地`outputs/diagnostics/coverage-world-geometry/`。这些数据不能解释为已具备专家能力；未发布未经验证的泛化结论。

额外因果审查逐位复现12回合64800个专家动作，在线GRU与整段输出最大差2.84e-7，未发现标签错位、hidden重置或CNN坐标/梯度连接错误。干预表明网络过度依赖上一拍命令：body模型清零seen/age后动作RMS差仅约2e-6—4e-6，移除上一命令则为0.20—0.25；直接复制上一拍的验证MSE甚至更低。低离线误差在这里允许学习捷径。完整证据在本地`outputs/diagnostics/coverage-causality-audit/`。

后续有依据的实验是仅在训练布局中，以保留真实物理、覆盖历史、学生hidden和教师完整历史的中途fork DAgger补采；prefix只warm RNN、分支计算loss，需要专门的掩码和数据版本。该功能当前未实现，也没有把它描述成已验证的解决方案。若采用stage/progress辅助监督，它只能是训练标签，不能成为部署时的专家输入或成功替代指标。

## 复现

所有业务源码在`src/`，入口为`main.py`和`run.sh`。`run.sh`逐项列出133个环境、实体、专家和显示配置字段，路径、训练、数据采集、专家批量验证和导出选项均显式传给Python。训练集/验证集按整场景划分，训练标签为专家原始动作，不是飞机执行后的速度。

本地`outputs/`和`tf-logs/`保留完整证据但不上传Git。6条TensorBoard标量是Train/Validation各自的Loss、Action_MSE、Action_MAE；当前为确定性连续策略，其他概率或离散指标不适用。最终回归通过数量及扩大专家测试结论以本地验收报告为准。
